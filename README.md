# 🚀 Jornada Back-end Developer: Do Zero à Prática com Node.js

Bem-vindo ao meu repositório de estudos focado em desenvolvimento back-end! Este espaço documenta minha evolução técnica através do **Bootcamp Sem Parar Corpay - Back-end do Zero a Prática**, onde o objetivo central é dominar o ecossistema **Node.js** para criar soluções escaláveis, seguras e prontas para o mercado.

## 🎯 Objetivos de Estudo

Meu principal objetivo é transitar de um conhecimento básico para um perfil de **Back-end Developer** capaz de atuar em projetos reais de alta complexidade. Para isso, foquei em:

1.  **Dominar a Linguagem:** Aprofundar-me em **TypeScript** como um superset essencial para prevenir bugs e aumentar a produtividade com tipagem estática.
2.  **Arquitetura Moderna:** Implementar APIs utilizando uma **arquitetura em camadas** (Routes, Controllers, Services, Repositories, Entities e Schemas) para garantir um código limpo e fácil de manter.
3.  **Performance e Eficiência:** Explorar o framework **Fastify** para criação de Minimal APIs de alto throughput, comparando-o com o Express em termos de latência e escalabilidade.
4.  **Integração com IA:** Aprender a conectar aplicações Node.js com as APIs da **OpenAI** para desenvolver funcionalidades inteligentes e agentes de IA.
5.  **Nuvem e DevOps:** Implantar e monitorar aplicações no **Microsoft Azure**, utilizando containers **Docker** e bancos de dados como **MongoDB** e **Azure Cosmos DB**.

## 🛠️ Stack Tecnológica

*   **Runtime:** Node.js
*   **Linguagem:** TypeScript
*   **Framework Web:** Fastify e Express
*   **ORM:** Prisma
*   **Validação:** Zod (Schemas)
*   **Banco de Dados:** MongoDB e Azure Cosmos DB
*   **Containerização:** Docker
*   **Nuvem:** Microsoft Azure (App Service, Azure Monitor)

## 📂 Projetos Destacados

*   🏎️ **Minimal API Fórmula 1:** Desenvolvimento de uma API leve e eficiente utilizando Fastify para operações CRUD otimizadas.
*   🍳 **MasterChef News API:** Construção de uma solução completa integrando Node.js, MongoDB e Docker, aplicando conceitos de POO e Injeção de Dependência.
*   💰 **API de Metas de Investimento:** Implementação prática de arquitetura em camadas com validação rigorosa via Zod e persistência com Prisma.
*   🤖 **Integração OpenAI:** Tutorial prático de conexão com modelos GPT para criar assistentes de código e agentes inteligentes.
